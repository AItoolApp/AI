## 摘要

作者提供一套「三步走」方案，让用户通过微信官方 ClawBot / iLink 接口，在微信里直接对话 Grok Bot。核心是一段详细提示词（「焚决」），让 Grok Bot 自己完成通道搭建、Webhook Routine 创建、云端转发程序编写，用户只需复制 URL/key 并扫码绑定。

**声明**：本文件为原教程归档整理，供内部分析使用。作者声称使用微信官方接口不会封号，但风险依赖调用方式、账号类型及微信当时规则，需自行核验。

## 为什么要接入微信

大家每天打开最多的还是微信。尤其是国内用户，微信是最符合社交和聊天习惯的入口。接入后，可在微信里直接指挥 Grok Bot 军团干活。

---

## 三步走操作

### 第一步：把「焚决」提示词发给 Grok Bot

在电脑端打开 Grok Bot，找到主 BOT，整段复制下面提示词发过去：

```
—— 焚决提示词开始 ——
我想把你接到我的微信上，让我能在微信里直接给你发消息、收到你的回复。请按下面的思路做，每做完一步告诉我结果，需要我操作的地方停下来等我。

1、先调研方案：腾讯「微信ClawBot」插件用的是 iLink 接口（ilinkai.weixin.qq.com）。请确认怎么用 getupdates 长轮询收消息、怎么用 sendmessage 回消息。整个程序只走出站请求，不要开公网端口。

2、在 Grok Bot 里建一个由 webhook 触发的 routine，名字可以叫「微信下旨入口」。建好后告诉我去 routine 面板复制 Webhook URL 和 key，然后弹出加密弹框让我填进去，不要让我在聊天里发明文。

3、在你的云端电脑上写一个小转发程序：收到微信消息后 POST 给这个 routine；你处理完以后，用一个 reply 脚本把回复发回微信，同时在我们的主聊天里同步一份。

4、等我在手机微信里启用 ClawBot 插件以后，生成二维码让我用手机扫码确认，同时给我一个可以在微信里直接打开的备用链接。二维码大约 5 分钟有效。

5、绑定成功后，提醒我先在 ClawBot 对话里发一句话，因为回复要用到这条消息带的 context_token。

6、规则：只认绑定的这一个人，别人的消息不处理；回复一律用纯文本，不要用 Markdown，因为微信不渲染 Markdown。

7、最后告诉我：云端电脑重启以后，怎么把转发程序重新拉起来；如果遇到错误码 -14（凭证过期），提醒我重新扫码。
—— 焚决提示词结束 ——
```

发完后，Grok Bot 会自己调研并执行接入方案。

### 第二步：复制 Webhook URL 和 key

1. 点开 Grok Bot 头像 → 右侧详情 → routine 面板。
2. 找到「微信下旨入口」，复制 Webhook URL 和 key。
3. Grok Bot 会弹出加密弹框，把 URL 和 key 粘贴进去并提交。
4. 界面显示「已安全保存并保持私密」即可。

这一步是给微信消息开一个专用入口。

### 第三步：微信扫码绑定

**3.1 确认微信版本并开启插件**
- iOS ≥ 8.0.70，Android ≥ 8.0.69
- 微信 → 我 → 设置 → 插件 → 找到「微信ClawBot」（红色小龙虾）并启用

**3.2 扫码**
- 回到 Grok Bot 说「插件开好了」
- 获取二维码，用微信扫一扫并确认
- 也可使用备用链接在微信内直接打开

**3.3 发第一句话**
- 绑定后，在微信 ClawBot 对话里先主动发一句话
- 成功标志：收到 Grok Bot 回复，且主聊天中同步了这段对话

---

## 温馨提醒

1. 二维码约 5 分钟有效，过期让 Grok Bot 重新生成。
2. 云端电脑重启后，需让 Grok Bot 重新拉起转发程序。
3. 同一微信不要同时接其他 OpenClaw，避免消息被分走。
4. 作者声称使用微信官方 ClawBot 接口，正常使用不会封号（需自行评估风险）。
