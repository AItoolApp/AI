# 素材图片投放区

> 把 WorkBuddy / 其他工具生成的图片放到本文件夹，我会整理后接入小程序当作知识卡片轮换背景素材。

## 放入规则

1. 文件名建议：`card-01.jpg`、`card-02.png`……（按数字顺序，方便轮换）
2. 尺寸建议：宽 480~750px，比例 9:16 或 1:1 都行
3. 单张大小建议：< 200KB（我会用 sips 统一压缩）
4. 风格建议：治愈系动漫风景 / 晨光 / 星空 / 书卷 / 森林 / 海边，低饱和、柔光、无文字

## 放入后

告诉我一声，我会：
1. 统一压缩/裁剪到小程序可用尺寸
2. 复制到 `weapp/src/assets/cardbg/extra/`
3. 接入知识卡片背景轮换逻辑（按日期或随机轮换）
