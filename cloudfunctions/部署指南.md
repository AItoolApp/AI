## 一、开通云开发

```
1. 打开微信开发者工具 → 导入项目
2. 顶部工具栏 → 云开发 按钮
3. 点击开通 → 选择免费环境 → 创建
```

免费额度（够用）：
- 存储 5GB
- 云函数 100万次/月
- 数据库 2GB

## 二、部署反馈收集函数

```
1. 微信开发者工具 → 右键 `weapp/cloudfunctions/feedbackCollect`
2. 选择「上传并部署：云端安装依赖」
3. 到云开发控制台 → 数据库 → 创建集合 feedbacks
```

验证：
- 小程序里提交反馈 → 云开发控制台 → feedbacks 集合出现记录

## 三、部署每日提醒函数

```
1. 微信开发者工具 → 右键 `weapp/cloudfunctions/dailyReminder`
2. 选择「上传并部署：云端安装依赖」
3. 修改 index.js 中的 YOUR_TEMPLATE_ID 为实际模板ID
4. 云开发控制台 → 云函数 → dailyReminder → 触发器 → 已自动创建
```

模板ID获取：
```
mp.weixin.qq.com → 功能 → 订阅消息 → 公共模板库
→ 搜索「打卡提醒」→ 选用 → 复制模板ID
```

## 四、小程序端接入反馈

编辑 `src/pages/manage/index.tsx` 的 `submitFeedback`：
```typescript
// 在本地保存后，同时调用云函数
wx.cloud.callFunction({
  name: 'feedbackCollect',
  data: { text: feedbackText, contact: feedbackContact }
})
```

小程序端已接入云能力初始化：
```typescript
if (wx.cloud) {
  wx.cloud.init({ env: 'cloudbase-d3g7noa8yac9d743c' })
}
```
